---
title: Ecosystem
---

The Crow CI ecosystem contains several parts which are spread across repositories.
Most of these can be found under the [Crow CI organization](https://codeberg.org/crowci).

The following list should help to understand the Crow CI ecosystem and its components:

| Name      | Purpose                          | Location |
| ----------- | ------------------------------------ | ---- |
| Crow main repo      | Server, Agent, CLI, Docs  | <https://codeberg.org/crowci/crow> |
| Autoscaler       | Crow Autoscaler for dynamic agent provisioning | <https://codeberg.org/crowci/crow-autoscaler> |
| Infrastructure    | Crow CI infrastructure (Website, DNS, Crow instances) | <https://codeberg.org/crowci/infrastructure> |
| Helm Chart    | Helm Chart for Kubernetes | <https://codeberg.org/crowci/helm> |
| Homebrew Tap    | CLI repository for macOS | <https://codeberg.org/crowci/homebrew-tap> |
| Crow Plugins    | Crow-maintained plugins | <https://codeberg.org/crow-plugins> |
| Image registry    | Container image registry | <https://codeberg.org/crow-plugins> |
