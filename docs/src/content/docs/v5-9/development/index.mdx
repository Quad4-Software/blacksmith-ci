1. [Setup](/dev/development/setup/) - Install required tools and dependencies
2. [Building](/dev/development/building/) - Build and test Crow components

4. [Architecture](/dev/development/architecture/) - System architecture overview

## Quick Start

```sh
# Clone the repository
git clone https://codefloe.com/crowci/crow.git
cd crow

# Install Go dependencies
just install-dev-deps

# Run tests
just test

# Start local development (requires .env file)
# Use VSCode "Crow CI" launch configuration
```
