---
title: "Notifications"
---

SMTP configuration for email notifications.
All variables are optional — notifications are disabled when `CROW_SMTP_HOST` and `CROW_SMTP_FROM` are not set.

## SMTP_HOST

- Name: `CROW_SMTP_HOST`
- Description: SMTP server hostname.
- Default: none

---

## SMTP_PORT

- Name: `CROW_SMTP_PORT`
- Description: SMTP server port. Port 465 uses implicit TLS (SMTPS), port 25 uses opportunistic TLS, and all other ports (including the default 587) require TLS.
- Default: `587`

---

## SMTP_USERNAME

- Name: `CROW_SMTP_USERNAME`
- Description: SMTP authentication username. When set, SMTP PLAIN authentication is used. Leave empty for unauthenticated SMTP.
- Default: none

---

## SMTP_PASSWORD

- Name: `CROW_SMTP_PASSWORD`
- Description: SMTP authentication password.
- Default: none

---

## SMTP_FROM

- Name: `CROW_SMTP_FROM`
- Description: Email address used as the sender ("From") for all notification emails.
- Default: none
