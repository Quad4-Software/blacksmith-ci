All configuration is done through environment variables. These pages describe the configuration of **Server**, **Agent** and the _optional_ **Autoscaler** in greater detail.

## Environment Variables

A complete reference of all environment variables is available in the [Environment Variables](/dev/configuration/env-vars/) section, organized by category:

- **Server**: Core settings, database, forge integration, security, defaults
- **Agent**: Connection settings, backends (Docker, Kubernetes, Local)
- **Autoscaler**: Pool and timing configuration
