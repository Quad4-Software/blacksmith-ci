A curated directory of plugins available for Crow CI.

## Plugin Sources

Crow CI plugins are distributed across several organizations:

- [crow-plugins](https://codeberg.org/crow-plugins) - Official Crow CI plugins
- [Woodpecker Plugins](https://woodpecker-ci.org/plugins) - Woodpecker CI ecosystem
- [woodpecker-community](https://codeberg.org/woodpecker-community) - Community-maintained plugins
- [thegeeklab](https://woodpecker-plugins.geekdocs.de/) - Popular plugin collection
- [appleboy](https://github.com/appleboy?tab=repositories&q=drone-&type=source) - Drone-compatible plugins

## Plugin Due Diligence

When evaluating a plugin, consider:

- **Maintenance status** - When was the last commit? (check the "Last Release" column above)
- **Documentation quality** - Is usage clearly documented?
- **Secret handling** - Does it properly document what secrets it needs?
- **Open issues** - Are there unresolved security concerns?

:::tip
You're trusting plugin maintainers with your secrets. Only use plugins from sources you trust.
:::
