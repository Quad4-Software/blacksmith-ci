This page provides information on how to (best) use Crow CI.
Besides basic examples, [advanced topics](/v4-5/usage/advanced/) are discussed and the full [syntax reference for workflow definitions](/v4-5/usage/workflow-syntax/) is given.

Depending on the use case, it might beneficial to also take a look at the [backend-specific options](/dev/configuration/server/#backends) for your instance.

A collection of usage examples can be found in the [Codeberg-CI/examples](https://codeberg.org/Codeberg-CI/examples) repository and the [Awesome Woodpecker](https://woodpecker-ci.org/awesome) page[^1].

Last, you might want to take a look at the [pipelines defined in the Crow CI project itself](https://codeberg.org/crowci/crow/src/branch/main/.crow).

[^1]: Crow is a hard-fork of Woodpecker and Woodpecker has been offered as a service by Codeberg for several years now.
  During that time, the Codeberg-CI/examples repo emerged.
