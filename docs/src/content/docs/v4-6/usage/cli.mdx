title: "CLI"
---

The Crow CLI (`crow`) allows you to interact with Crow CI from the command line.
You can manage repositories, pipelines, secrets, and more.

## Installation

### Binary Download

Download the CLI from the project's [releases page](https://codefloe.com/crowci/crow/releases).
Choose the appropriate binary for your platform.

:::note
A homebrew tap for simplified installation on macOS is planned.
:::

### Container Image

The CLI is also available as a container image:

```sh
docker run --pull always \
  -e CROW_TOKEN=$CROW_TOKEN \
  -e CROW_SERVER=$CROW_SERVER \
  --rm -it codefloe.com/crowci/crow-cli:dev info
```

:::note
The container image is named `crow-cli` to align with server and agent image naming. The executable inside is named `crow`.
:::

## Configuration

The CLI requires two environment variables:

| Variable | Description |
| --- | --- |
| `CROW_SERVER` | URL of your Crow CI server (e.g., `https://ci.example.com`) |
| `CROW_TOKEN` | Personal access token from the Crow CI web interface |

You can generate a token in the Crow CI web interface under **Settings > Personal Access Tokens**.

## Common Commands

### Repository Management

```sh
# List repositories
crow repo ls

# Show repository info
crow repo info owner/repo

# Sync repositories from forge
crow repo sync
```

### Pipeline Management

```sh
# List recent pipelines
crow pipeline ls owner/repo

# Show pipeline details
crow pipeline info owner/repo <pipeline-id>

# Trigger a new pipeline
crow pipeline start owner/repo

# Stop a running pipeline
crow pipeline stop owner/repo <pipeline-id>
```

### Secrets Management

```sh
# List secrets
crow secret ls owner/repo

# Add a secret
crow secret add owner/repo --name SECRET_NAME --value "secret-value"

# Remove a secret
crow secret rm owner/repo SECRET_NAME
```

### Local Pipeline Execution

```sh
# Run pipeline locally (requires Docker)
crow exec

# Run with specific workflow file
crow exec --workflow .crow/build.yaml
```

### Linting

```sh
# Lint pipeline configuration
crow lint .crow/
```

## Getting Help

```sh
# Show all commands
crow --help

# Show help for a specific command
crow repo --help
crow pipeline start --help
```
