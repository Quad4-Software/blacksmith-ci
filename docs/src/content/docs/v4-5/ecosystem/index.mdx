---
title: "Ecosystem"
---

The Crow CI ecosystem contains several parts which are spread across repositories.
Most of these can be found under the [Crow CI organization](https://codefloe.com/crowci).

The following list should help to understand the Crow CI ecosystem and its components:

| Name      | Purpose                          | Location |
| ----------- | ------------------------------------ | ---- |
| Crow main repo      | Server, Agent, CLI, Docs  | [codefloe.com/crowci/crow](https://codefloe.com/crowci/crow) |
| Autoscaler       | Crow Autoscaler for dynamic agent provisioning | [codefloe.com/crowci/crow-autoscaler](https://codefloe.com/crowci/crow-autoscaler) |
| Infrastructure    | Crow CI infrastructure (Website, DNS, Crow instances) | [codefloe.com/crowci/infrastructure](https://codefloe.com/crowci/infrastructure) |
| Helm Chart    | Helm Chart for Kubernetes | [codefloe.com/crowci/helm](https://codefloe.com/crowci/helm) |
| Homebrew Tap    | CLI repository for macOS | [codefloe.com/crowci/homebrew-tap](https://codefloe.com/crowci/homebrew-tap) |
| Crow Plugins    | Crow-maintained plugins | [codefloe.com/crow-plugins](https://codefloe.com/crow-plugins) |
| Image registry    | Container image registry | [codefloe.com/crow-plugins](https://codefloe.com/crow-plugins) |
